# 建议与提问提醒

版本：1.2.1 · 2026-11-02

双击 Windows 托盘里的蓝色铃铛，打开“通知设置”。两个新增开关都立即保存，退出或重启电脑后仍保留。无需再点“保存更改”。

1.2.1 将默认窗口内容区增高为 920 × 860，以完整显示新增选项；小屏幕仍可滚动。

| 开关 | 手机显示 | 触发条件 |
|---|---|---|
| 输入框建议提醒 | Codex 有新的输入建议 | Codex 生成可按 Tab 采纳的下一步输入建议 |
| 需要回答时提醒 | Codex 需要你回答 | Codex 通过本机提问工具展示问题或选项 |
| 手机通知 | 总开关 | 关闭后暂停所有通知，保留已有待发 |

正常回复仍显示项目名称、用户输入和本轮回复。建议通知只包含项目及建议；提问通知包含项目、问题及选项。两类交互提醒的项目名取事件工作目录末级目录，未提供时显示“未知项目”。每条最多 1024 字符，超长截断。

## 首次启用

1. 在 Codex“设置 → Hooks”刷新列表。
2. 查看 `PreToolUse` 项“Pushover 提问与选择提醒（EXE）”，信任该项；也可从“Review hooks”选中后点“Allow selected”。
3. 打开所需开关。原有 `UserPromptSubmit` 和 `Stop` 定义保持不变；建议提醒沿用它们。

新安装或旧配置没有这两个选项时，默认关闭，需要自行开启。开关与 hook 信任是两件事：开关打开，并不代表新增 hook 已获信任。

## 工作原理

`UserPromptSubmit` 识别明确的应用生成指令，只保存该回合的分类标记；`Stop` 读取 `suggestion` 字段，按建议开关决定是否入队。普通用户主动请求的建议、JSON 回复不受此分类影响。空建议不发送。

`PreToolUse` 仅匹配 `request_user_input`、`request_user_input_async` 及其 `functions.` 前缀形式。它读取问题和选项，保存待发记录后立即返回 `{}`。不会替用户回答、批准或拦截原工具调用。当前本机引擎协议提供 `turn_id`、`tool_use_id`；字段和工具覆盖范围以[官方 Hooks 文档](https://learn.chatgpt.com/docs/hooks)为准。

正式回复和建议按真实 `session_id + turn_id` 去重；提问额外加入事件类别和 `tool_use_id`，因此同一轮多个问题与最后回复互不覆盖。并发重复事件仍只落一条记录。发送由原有 EXE 后台处理，继续使用持久队列、网络超时和退避重试。

关闭某一类提醒会取消它尚未发送的记录，重新开启不会补发这些已取消记录。已开始发送的请求无法撤回。总开关“手机通知”仍沿用暂停并保留待发的行为。

## 命令行管理

```powershell
$exe = Join-Path $env:LOCALAPPDATA 'CodexPushover\CodexPushover.exe'
& $exe --suggestions on
& $exe --suggestions off
& $exe --input-reminders on
& $exe --input-reminders off
& $exe --status
```

配置保存在 `%LOCALAPPDATA%\CodexPushover\notification-options.json`：`notify_composer_suggestions` 与 `notify_input_requests`，均为 JSON 布尔值。建议通过界面或上述命令修改，以便同步处理待发记录。

## 验证与边界

39 项隔离核心测试涵盖开关持久化、正常回复保留、空建议、同轮多次提问、并发去重、失败重试、关闭取消待发和 Unicode 截断；8 项布局检查包含小窗口滚动到输入控件。它们不等于实际桌面触发或手机已收到。

安装电脑上的两个合成发送测试均获 HTTP 200 + status=1，三项 hooks 已受信任。用户报告收到真实提问通知，但未在本机队列中关联到对应的新 hook 记录；因此，真实提问的完整触发链路仍未核实。详见[使用说明的验证记录](使用说明.md#验证记录)。

提问提醒只覆盖经过上述本机工具路径的请求；普通文字问句在正式回复结束后通知。它不监控 ChatGPT 网页，不保证覆盖所有云端界面或权限审批提示。收到提醒后仍须回到 Codex 回答。只有 HTTP 200 且响应 status=1 才记为“Pushover已接受并入队”，手机接收由用户确认；超时重试不保证严格只发送一次。

如果只需要正式回复通知，将两个交互提醒开关都关闭即可。
